Dissertation

My dissertation on Reinforcement Learning for Physics Simulations: A Comparison of A2C, PPO, and TRPO.
The project is a comparison of three RL algorithms: Advantage Actor-Critic (A2C), Proximal Policy Optimization (PPO), and Trust Region Policy Optimization (TRPO) in the Acrobot environment (GIF of environment on the left). Feel free to test or re-train the algorithms and see how well they do in the environment.

Multilayer Perceptron Neural Network

This project implements a basic Multi-Layer Perceptron (MLP) for binary classification using a feedforward neural network with backpropagation. The network consists of input nodes, hidden nodes, and output nodes, and is trained using gradient descent.

Gradient Descent Algorithm

This project demonstrates a simple implementation of the Gradient Descent algorithm for binary classification using a logistic regression model. The program reads data from a file, applies gradient descent to adjust weights, and prints the results for each epoch.

Checklist App

A React Native application that allows you to manage tasks within lists, capture images, and view completed tasks. It uses AsyncStorage for local data persistence and Redux for state management.
